치과 광고 클라이언트에게서 "요즘 네이버 느낌이 다른데, 알고리즘 바뀐 거 맞죠?" 질문이 연달아 왔다. ADVoost 전환 이후 체감이 달라졌다는 피드백이 늘었다. 단순히 "바뀐 것 같다"는 답변은 쓸모없다. 공식 공지 기반으로 파봤다.

**TL;DR** `research` 스킬로 4 에이전트를 병렬 디스패치해 네이버 광고 공지 17건을 분석하고, 증거 등급 5단계로 분류해 의료광고 HTML 보고서를 자동 생성했다. 작업 중 2026-05-07 네이버 AI 브리핑 광고 베타 시작을 실시간으로 캐치했다.

## 4 에이전트 병렬: 단일 에이전트론 breadth가 부족하다

세션 1이 핵심이다. 네이버 검색·플레이스·광고 알고리즘 전체를 한 번에 커버해야 했다. 단일 에이전트로 돌리면 한 각도만 깊어지고 나머지가 얕아진다. `research` 스킬 규칙대로 4개 각도로 분해했다.

1. 공식 공지 기반 사실 확인 (네이버 Ads 공지 크롤링)
2. 자연검색·플레이스 랭킹 신호 변화 (커뮤니티 + 업계 관찰)
3. ADVoost 매칭 로직 변화 분석
4. 의료·치과 업종 특수 적용 사항

각 에이전트 프롬프트에 "출처 URL 필수, 다른 에이전트와 겹치는 영역 플래그" 조건을 명시했다. 스킬이 생성하는 프롬프트 골격은 이렇다.

```
You are Research Agent #2. Your angle: 자연검색/플레이스 랭킹.
- WebSearch + WebFetch 적극 활용
- 1500단어 이내 마크다운 리턴
- 출처 URL 필수
- 자매 에이전트와 중복 영역 플래그
```

단일 메시지에서 `Agent` 호출 4개를 동시에 보냈다. 순차로 돌리면 80분이 걸릴 작업이 21분으로 끝났다.

세션 1 도구 사용: `Agent(8)`, `Read(5)`, `Bash(4)`, `TodoWrite(3)`, `Write(2)`.

## 에비던스 규율: Codex가 잡아낸 미확인 주장

4개 에이전트 결과를 합치니 문제가 드러났다. 공식 공지에 있는 내용과 커뮤니티 관찰이 섞여 있었다. 의료광고 compliance 특성상 "알고리즘 변화"라는 표현을 공식 확인 없이 쓰면 안 된다.

세션 2에서 별도 시너시스 리뷰 (`claude_synthesis_review.md`)를 만든 이유다. `naver_ads_notice_extracts.json` 공지 15건을 기준으로 등급을 나눴다.

```
공식 확인  → 광고 공지에 명시된 것만
             (확장검색, ADVoost, 병의원 소재, 플레이스광고 테스트)
도움말 해석 → 공식 도움말에서 추론 가능한 것
업계 관찰  → 공지 없이 커뮤니티·실무에서 관찰된 것
합리적 유추 → 공식 자료 기반 추론
확인 필요  → 출처 부재 또는 미확인 주장
```

Codex 크로스체크가 한 건 잡았다. 2026-05 플레이스광고 적용 공지가 추출된 JSON에 없다는 것. 해당 항목은 즉시 `확인 필요`로 강등했다. 리서치 결과를 그냥 믿지 않고 독립 검증을 거치는 게 왜 필요한지 보여주는 사례다.

세션 2 도구 사용: `Read(4)`, `Bash(4)`, `Write(2)`, `Grep(1)`. 소요 5분.

2026-05-07, 즉 어제 네이버가 'AI 브리핑' 광고 베타를 시작했다.

`WebSearch(9)` + `WebFetch(6)` 조합으로 확인한 내용:

- 헬스케어 버티컬 AI는 연내 로드맵에 명시

이 발견이 당일 클라이언트 브리핑에 바로 들어갔다. 데일리 에이전트가 아니었으면 며칠 후에나 알았을 내용이다.

## 이 작업에서 배운 것

**병렬 에이전트는 breadth 문제에 효과적이다.** 단일 에이전트 4회보다 동시 4 에이전트가 빠르고 균형 잡힌 결과를 낸다. 각 에이전트가 다른 각도를 맡으니 사각지대가 줄었다.

**에비던스 등급을 강제하지 않으면 공식 확인과 추론이 섞인다.** 명시적인 분류 단계를 별도 세션으로 뺀 것이 맞는 판단이었다. Codex 크로스체크가 미확인 주장을 잡아낸 게 그 과정에서 나왔다.

**데일리 에이전트는 정보 지연을 없앤다.** `medical_dental_ads_daily_goal.md`에 "무엇을 확인할지"를 정의해두면 에이전트가 공식 소스를 순회하며 변화를 실시간으로 탐지한다. 네이버 AI 브리핑 베타 발견이 그 예다.

**산출물을 파일로 유지하면 세션이 끊겨도 손실이 없다.** 세션 1에서 `API Error: Overloaded`가 터졌지만 이미 생성된 `research-minutes.md`를 기반으로 세션 2가 이어받았다. 상태를 파일로 관리하는 워크플로우의 실질적인 이점이다.
