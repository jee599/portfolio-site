27시간 28분, 335번의 도구 호출. preterview에 AI 비주얼 면접 기능 하나 붙이는 데 든 Claude Code 세션 하나의 스펙이다.

**TL;DR** HeyGen + Simli로 실사 아바타 면접관 3인을 구현하고 립싱크까지 붙였다. 비용을 20분 세션당 $1 이하로 줄이는 게 구현 자체보다 어려웠다.

## "3D 말고, Zoom처럼 해줘"

시작은 "비주얼 면접 기능 — 3D 렌더링으로 면접관 3명 얼굴, 립싱크 맞추고, 내 화면도 나오게"였다. 타당성 검토부터 돌렸다.

두 스코프로 나눴다. 스코프 A는 턴 기반(푸시투토크, HTTP 유지), 스코프 B는 진짜 실시간(WebRTC 연속 대화). B는 구현 복잡도 2배에 비용 10배다. 스코프 A로 결정.

3D 아바타를 먼저 붙였다. 동작은 했다. 그런데 돌아온 피드백이 "저렇게 말고 zoom이나 화상면접처럼 해줘"였다. 실사(photoreal) 아바타로 방향을 바꿨다.

## HeyGen + Simli 조합을 선택한 이유

실사 아바타 벤더를 멀티 에이전트 워크플로우로 리서치했다. 비교 대상은 HeyGen Streaming API, Simli, D-ID, Tavus였고, 각 벤더의 2026 현재 가격과 한국어 지원 여부를 실측으로 확인했다.

선택 기준은 세 가지였다. 스트리밍 레이턴시(턴 기반이어도 응답이 3초 넘으면 대화 흐름이 깨진다), 동시 스트림 수(면접관이 3인이다), 한국어 TTS 품질.

최종 조합은 HeyGen(아바타 스트리밍) + Simli(립싱크). HeyGen은 무료 티어에서 API 키만 있으면 테스트 가능했고, Simli는 입모양 추적 정확도가 다른 벤더보다 눈에 띄게 나았다. `SimliAvatarTile.tsx`, `HeyGenAvatarTile.tsx`를 새로 만들고 `VisualInterviewPoc.tsx`에서 3인 패널로 조합했다. `next.config.ts`에 외부 스트리밍 도메인 허용 설정도 추가했다.

## 비용 $1/세션이 진짜 싸움이었다

"지금 너무 비싸 말도 안돼 면접 한 번에 1달러 정도 해야돼 20분에 그 이하"

초기 구현은 20분 세션에 $5~10이 나왔다. HeyGen 스트리밍 요금이 예상보다 높았다. 비용 최적화 워크플로우를 별도로 돌렸다 — 24 에이전트, 880k 토큰 투입.

핵심 최적화 세 가지로 $1/세션 이하 목표를 달성했다. 첫째, 면접관 3인을 동시에 스트리밍하지 않는다. 현재 발화 중인 1인만 활성화한다. 둘째, TTS는 Web Speech API로 대체 가능한 구간에서 대체한다. 셋째, HeyGen 스트리밍은 면접관이 실제로 말하는 구간에만 켠다. 턴 기반이라 면접관 대사를 미리 생성해 타이밍을 추출하는 게 가능했기 때문이다.

## 광고 리서치도 워크플로우로 돌렸다

비주얼 면접 구현이 끝난 뒤, 광고 전략 세션이 별도로 있었다. "인스타가 나아? 얼마를 어떤 타겟에 태우는게 가장 효과적인지 객관적인 수치랑 근거로"라는 요청이었다.

5개 병렬 리서치 에이전트를 돌렸다 — 국내 채널(네이버 파워링크, 메타 코리아), 글로벌 메타+틱톡, 구글, 유튜브, 취준생 밀집 채널 분석. 총 24 에이전트, 880k 토큰, 245 웹 서치. 결과 도출까지 8시간 46분이 걸렸다.

결론은 네이버 파워링크(한국) + Google Search Ads(글로벌) 조합. 취준생 의도 키워드는 CPC가 낮고 전환 의도가 높다는 데이터가 나왔다. 광고 픽셀(`consent-banner.tsx`, `conversions.ts`, `track.ts`)도 이 세션에서 붙였다.

## 경쟁사가 6일 전에 출시했다

코드잇이 AI 모의면접 서비스 어센트(Ascent)를 조사 시점 기준 6일 전에 출시했다. 프리터뷰와 겹치는 부분이 있는지 확인했다.

워크플로우: 4갈래 병렬 조사(어센트 실서비스 실측, 코드잇 전략·KADE 인수 맥락, 국내 AI 면접 경쟁 지형, 핵심 주장 교차검증) → 5건 주요 클레임 개별 검증 → 종합.

검증 과정에서 중요한 수정이 있었다. "GitHub/포트폴리오 URL 분석 기능 있음"이라는 클레임이 refuted — 어센트에는 이 기능이 없다. 어센트는 한국 전 직군 취준용(마케팅·기획·PM·제조 포함 ~113개 기업 맞춤 면접), 한국어 전용이다. 프리터뷰는 개발자 특화 글로벌. 겹치는 건 "음성 모의면접 + 다차원 리포트" 골격뿐으로, 정면충돌이 아니라 인접 시장이라는 결론이 나왔다.

비주얼 면접 세션 335 호출의 분포: `Bash(110), Edit(72), mcp__claude-in-chrome(48), Write(18)`. 브라우저 자동화가 14%를 차지했다. HeyGen 대시보드 확인, 실제 립싱크 결과 시각 검증, Simli 크레딧 잔액 확인을 Claude가 직접 브라우저를 조작해서 처리했다.

이번 작업에서 패턴이 하나 굳어졌다. 벤더 비교, 키워드 CPC 조사, 경쟁사 분석 같은 리서치는 멀티 에이전트 워크플로우가 압도적으로 빠르다. 반면 실제 컴포넌트 수정은 컨텍스트를 가진 단일 세션이 낫다. 리서치는 워크플로우, 구현은 직접.
