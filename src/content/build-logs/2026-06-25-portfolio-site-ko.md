이메일 한 통 쓰려다가 185개 IT 기관 타겟 리스트가 나왔다. 세션 하나에서 303 tool call, Bash 109번, Edit 70번, Gmail 드래프트 MCP 20번. 10개 세션, 750+ tool call, 이틀 사이에 Preterview 마케팅 캠페인 자산 전체가 만들어졌다.

**TL;DR** "판매 이메일 양식 하나"가 185개 기관 개인화 아웃리치 + 광고 전략 보고서 + GA4·네이버 픽셀 + GEO/AEO + 로고 6종 + 홈페이지 개편으로 확장됐다. 멀티에이전트 워크플로 없이는 불가능한 일이었다.

## 콜드메일 한 통이 198개 기관으로 불어난 이유

시작은 단순했다. "preterview를 판매하는 한페이지나, 이메일 양식을 하나 만들어줘."

영업 랜딩 페이지를 먼저 만들었다. preterview의 `globals.css`에서 violet 액센트(`#6E56F7`)와 near-black 히어로 토큰을 그대로 바인딩했다. 그 다음 이메일 초안을 만드는 과정에서 30초 데모 영상을 이메일에 넣으려는 시도가 이어졌다. `<video>` 태그, GIF 임베드, 오버레이 HTML, 여러 방법을 연달아 시도했는데 전부 이메일 클라이언트 보안 정책에 막혔다. "계속 안 되는데 해결 못 할 거면 그냥 빼"라는 한마디로 정리됐다. 정적 스크린샷에 링크를 다는 방식으로 교체했다.

"대학교취업지원센터에 보내고 싶다"가 나온 시점부터 방향이 달라졌다. Dynamic Workflow 첫 번째 돌림에서 95개 기관(실측 공개 이메일 92개), 두 번째에서 198개까지 확장됐다(국내 72, 국외 113). 추측 이메일은 프롬프트에 박아서 아예 생성 안 하도록 했다.

기관별 개인화 초안에서 "워크숍 연계" 같은 실현 불가 제안은 피드백 한 번에 전부 잘라냈다. 최종 카피에 들어간 핵심 조건은 "면접당 2달러 내외의 API 비용만 받는 프로모션 기간"이었다. "공짜로 줄 수는 없잖아"라는 피드백 그대로 반영한 결과다.

결과물: `~/preterview/marketing/send_outreach.py`(CSV 쓰로틀 발송 스크립트), `preterview-sales.html`, `preterview-email-univ.html`, `cold-emails.md`.

## 24개 에이전트, 880k 토큰짜리 광고 전략

"인스타가 나아? 얼마를 어떤 타겟에 태우는 게 가장 효과적인지." 예산 기준 50만원.

Dynamic Workflow 4개가 순차로 돌았다. 플랫폼별 CPC·도달·CTR 실측 수집 → 3개 실행 에셋 제작 → 채널별 예산·기대 효과 퍼널 모델 → 네이버 파워링크 최적 키워드 실측 조회. 총 24개 에이전트, ~880k 토큰, 245회 웹 툴 사용.

여기서 어드버서리얼 검증 에이전트가 따로 돌면서 17개 핵심 수치 중 13개를 수정했다. 원본 리서치 에이전트가 오래된 데이터를 썼거나 틀린 경우들이었다. 검증 에이전트를 분리해서 돌리는 게 왜 필요한지를 숫자로 보여준 케이스다.

결론은 네이버 파워링크. "면접말버릇", "면접습관교정" 같은 롱테일 키워드가 CPC 낮고 전환 의도가 명확했다. 카피는 제목 15자·설명 45자 제한에 맞춰 그룹별로 뽑았다. 구글 RSA 한국어·영어도 같이 나왔다.

픽셀 설치도 같은 세션에서 진행됐다. `.env.local`에 `NEXT_PUBLIC_GA_ID=G-ES6SENFGM2` 추가, `layout.tsx`에 Next.js `Script` 컴포넌트 삽입. 네이버 전환 추적은 비즈채널 검수 통과 → 자가설치 신청 완료, 안내 메일 대기 중이다.

GEO/AEO도 붙었다. `~/preterview/public/llms.txt`, `app/robots.ts`, `app/sitemap.ts`, `components/marketing/structured-data.tsx`. ChatGPT·Perplexity·Gemini가 "모의면접" 쿼리에서 preterview.com을 인용하도록 하는 작업이다.

## GPT Image 2로 로고 6종, 하나 선택

"JL로 할까? 다양한걸로 만들어서 피드백받아봐."

로고 생성 스크립트를 짜고 6가지 방향을 정의했다. 방향 1로 테스트 후 나머지 5개를 병렬 생성했다. 인디고 JL 모노그램이 선택됐고 `~/jidonglab-site/app/icon.svg`로 들어갔다. `BrandMark.tsx` 컴포넌트로 분리해 Nav와 사이트 전반에 적용했다. 브랜드 메모리 `reference_jidonglab_brand.md`에도 박았다.

jidonglab.com 홈페이지 개편도 같이 진행됐다. Preterview가 앞에, 치과광고대행 대시보드 예시(수치·이름 제거)가 중간, spoonai.me와 나머지가 뒤에 오는 구조다. `DentalShowcase.tsx`, `Flagship.tsx` 컴포넌트가 새로 생겼다.

## 나머지 세션들

**동백유디치과 정기 측정** (2 tool call): `dental-clinic` 전담 에이전트에 위임. 메인 세션 tool call 단 2개로 전체 측정 → 기록 → 다이제스트 → 배포가 처리됐다. '동백 임플란트' 블로그 순위가 경쟁사 도배로 12위 밖에서 3위로 복귀한 것도 이 기간에 확인됐다.

**지원사업 서칭** (67 tool call): 치과광고대행·AI모의면접·개인사업자 세 갈래. 6/22 42건 검증 자료 위에 6/24 기준 재실측을 얹었다. 이 세션에서 Preterview IR 자료도 만들었다.

**머니투데이 굿컴퍼니대상 메일** (5 tool call): "AI 모의면접 서비스 부문 수상" 초청 메일 분석. 웹 검색 4번으로 패턴 확인. 상은 미끼, 실제 청구 항목은 "취재지원 멤버십"과 광고비인 유료 수상 스킴. 거절.

**유디치과 네이버 블로그 발행** (53 tool call): 2편 초안 최종 패키지 완성 후 발행 승인. 폴더 + txt 파일로 네이버 에디터에 복붙할 수 있게 포맷했다. 태그 최대 30개 제한도 반영했다.
