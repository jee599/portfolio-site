하루에 Claude Code 세션이 10개였다. 총 559번의 도구 호출, 21개의 파일 생성. 그 중 한 세션이 21시간 56분, 294번의 도구 호출로 기존 커피챗 사이트를 처음부터 다시 썼다.

**TL;DR** 멘토-멘티 매칭이었던 커피챗을 이력서 빌더·포트폴리오 분석·AI 모의면접 3-기능 플랫폼으로 교체했다. 같은 날 치과 광고 채널 전수 조사를 22개 병렬 에이전트로 돌렸다.

## 커피챗, 방향을 완전히 바꾸다

시작 프롬프트는 이랬다:

> "커피챗 사이트를 리뉴얼해서 멘토와 멘티를 이어주는 플랫폼이 아니라, 1. 내용채우면 이력서 만들어주고, 2. 포트폴리오 점검해주고 3. 에이전트 3명을 둬서 에이전트는 글로 쓰고, 사람은 말로 하게 해서 모의 면접을 하는 사이트를 만들고 싶어"

기존 코드 재사용이 아니라 `~/coffeechat`에 Next.js 프로젝트를 새로 만들었다. Claude가 결정이 필요한 부분을 먼저 물어봤다 — 음성 TTS 지원 여부, 면접관 역할 분담 방식. 음성은 불필요하다고 했고, 나머지는 합리적인 디폴트로 바로 빌드를 시작했다.

API 라우트 5개(이력서 polish, 포트폴리오 분석, 면접 setup·turn·report), 공유 타입, Anthropic 클라이언트, 이력서 위저드 5단계, 포트폴리오 체크, 모의면접 인터랙션까지 한 세션에 다 들어갔다. Bash 144번, Edit 40번, Write 29번이 이 세션의 도구 분포다. Bash 대부분은 빌드 확인과 타입체크였다.

## 이미지 루프: 손그림 → 테크 → toss

디자인 피드백이 4라운드에 걸쳐 쏟아졌다. "AI로 만든 티가 난다", "버튼 위치가 안 맞는다", "주황 갈색 별로 안 예뻐", "전체적으로 색조합을 고려하지 않은 디자인이다".

이미지 생성이 세 번 돌았다. 첫 번째는 손그림 스타일 — 피드백: "더 전문적이어야 한다". 두 번째는 3D 전문 스타일 — 피드백: "주황 갈색 별로 안 예쁘다". 세 번째가 "toss 톤으로 맞춰줘".

각 라운드마다 `scripts/gen-assets.mjs`를 백그라운드 TaskCreate로 돌렸다. 6개 에셋을 병렬 생성하고, 브라우저 MCP(`mcp__claude-in-chrome__browser_batch`)로 실제 렌더를 확인한 뒤 다음 지시를 줬다. 브라우저 도구가 세션 전체에서 34번 호출됐는데, 대부분 렌더 확인이었다.

파비콘 이슈도 따로 나왔다. "파비콘 아직 로고 이상한데?" — 배경 투명도 처리 문제였다. 이것도 재생성으로 해결했다.

## AI 모의면접 로직을 어떻게 설계했나

면접 UX 요구사항이 구체적이었다:

> "경험에 대한 꼬리 무는 질문, 답변 내용에 대해서 더 파고드는 질문, 잘 모른다고 하면 다른 부분으로 파고드는 질문, 답변이 부족하면 추가 질문"

이 요구사항 전체를 `app/api/interview/turn/route.ts`의 시스템 프롬프트로 녹였다. 포트폴리오·공고를 입력받으면 그 내용 기반으로 면접이 시작되고, 입력이 없으면 분야·경험·해본 일을 먼저 물어보는 setup 플로우가 붙었다. 면접 질문 카테고리는 포폴 기준·기본지식·전문지식·서버/게임/백엔드/프론트엔드별로 분기된다.

"Opus로 10~20분 면접이 얼마나 들어?"라는 비용 질문도 나왔다. 입출력 토큰을 추산해서 $0.45~$1.20 범위가 나왔다. Sonnet 대비 차이는 꼬리 무는 질문의 자연스러움과 답변 분석 깊이라고 설명했다.

클라이언트 로직 전체를 코드 리뷰 에이전트에 넘겼다. 이력서 위저드 5종, 포트폴리오 3종, 면접 4종, lib 4종, demos.tsx가 대상이었다. stop hook이 TODO 잔재를 두 번 잡아냈고, 그때마다 정리했다.

## 22-에이전트 병렬 리서치: 치과 광고 채널 전수 조사

세션 10에서 `ultracode` 모드로 치과 온라인 광고 채널 리서치를 돌렸다.

```
/effort ultracode
전체적으로 의료 광고, 치과 광고 온라인에서 진행할 수 있는 모든 부분에
최신화된 내용으로 서칭해주고...
```

Workflow가 22개 에이전트를 12개 차원에 병렬 배치했다: 네이버 검색광고·스마트플레이스·블로그 알고리즘·AEO/GEO·구글·메타·유튜브·카카오/당근·의료법·리뷰 합법경계·예약플랫폼·비용 벤치마크. 각 차원 리서치가 끝나면 고위험 6개 차원은 핵심 주장 5개씩 별도 적대검증 에이전트가 교차 확인했다.

결과는 48KB 채널 카탈로그(`_kb/research-online-channels-2026-06.md`), 판정표 24행(권장 9·조건부 7·비권장 7)이었다. 적대검증에서 틀린 주장 4건을 잡아 정정했다. "헌재 비급여 할인 결정은 2025년"이라는 주장이 실제로는 2019-05-30 결정이었던 게 대표적이다.

리서치 도중 dental-clinic 에이전트가 API 과부하(529)로 65번 호출 후 강제 종료됐다. 파일 상태를 확인했더니 대부분 완료된 상태였고, 남은 부분만 재실행해서 마무리했다.

## 텔레그램 버그: 비활성화된 플러그인

세션 1에서 텔레그램 연결을 확인하고 "봇 토큰 입력 → `--channels` 플래그로 재실행" 세 단계를 안내했다. 세션 2에서 "연결 안됐어"가 다시 왔다.

실제 원인은 단순했다. `~/.claude/settings.json`에서 `"telegram@claude-plugins-official": false`로 비활성화돼 있었다. 5월 말 하네스 정리 때 플러그인을 일괄 비활성화하면서 같이 꺼진 것이었다. `true`로 바꾸니 즉시 연결됐다.

세션 9에서는 텔레그램으로 사주 프로젝트 지시가 들어왔다. "사주 프로젝트 정리해줘" → 메모리에서 컨텍스트 복원, 상태 요약을 텔레그램으로 회신. "깃연동 켜줘" → GTM 실행팩 2종(일본·미국) 백그라운드 에이전트로 병렬 생성. 세션 종료 전 AI 사주챗 e2e 테스트까지 완료했다.
