10개 세션, 1,394번의 도구 호출. 최장 세션은 14시간 23분짜리 커피챗 어드민이었고, 가장 짧은 건 1분짜리 cron 상태 텍스트 수정이었다. 하루 동안 건드린 프로젝트가 다섯 개였다: 치과 마케팅, spoonai.me, daymoon 포토그래퍼 사이트, 사주, 커피챗.

**TL;DR** claude-fable-5 기반 세션에서 세션 한도를 여러 번 맞으면서도 프로젝트마다 배포까지 끝냈다. 1분짜리 수정과 14시간짜리 전체 재구축이 같은 날 일어났다.

## 치과 원장님 발표 덱 — 20장에서 13장으로

세션 1(2h 58min, 175 tool calls)은 치과 프로젝트 원장 미팅 준비였다. `~/dental-promo/dongbaek-uddental/`에 쌓인 데이터를 꺼내 프레젠테이션 2종을 만들었다: HTML 슬라이드 덱(방향키·클릭 넘김)과 슬라이드별 발표 대본.

첫 초안이 20장이었다. 피드백: "너무 내용이 많고 전문용어가 많다, 수치는 말로 풀어달라." 방향 잡고 바로 재작업했다. `CPC`, `AEO` 같은 용어를 전부 걷어냈고 "클릭 1번 약 3만 7천 원"처럼 말로 풀었다. 파트 구분 슬라이드(검정 배경)도 제거했다. 20장 → 13장.

발표 대본은 마크다운으로 썼다가 HTML로 변환 요청이 들어왔다. 슬라이드 번호 칩 클릭하면 해당 위치로 점프하는 구조를 넣었다 — 발표 중 길 잃었을 때 빠르게 찾을 수 있게. "30초 이내", "★ 오늘의 목적" 같은 태그도 달았다.

마지막에 이메일 발송 요청이 왔다. AppleScript로 Mail.app을 제어해서 두 파일을 naver.com으로 보냈다.

도구 분포: Edit 68회, Bash 61회, Read 15회.

## spoonai.me 퍼널 버그 — Supabase 키가 없었다

세션 4(39min, 30 tool calls)에서 spoonai.me 파이프라인 전수 감사를 Workflow로 돌렸다. 에이전트 11개, 감사 3종(파이프라인·이메일·사이트) + 딥리서치 4종 + 적대검증.

가장 심각한 발견: 사이트 구독 신청 이메일은 Supabase DB에 저장되는데, 발송 스크립트(`send-email.js`)에 `SUPABASE_SERVICE_ROLE_KEY`가 없어서 DB를 못 읽는 상태였다. 4월 13일 이후 구독자에게 메일이 한 통도 안 간 것이다. 받는 사람도 수신거부 링크가 404였다. 퍼널이 입구와 출구 두 군데서 동시에 끊겨 있었다.

리서치 결과에서 흥미로운 포인트도 나왔다 — 범용 AI 데일리는 이미 포화 상태이고, "한국 AI를 영어로 데일리 추적하는 매체"는 아직 비어있는 슬롯이라는 것. 파이프라인이 살아 있다는 것을 확인한 다음 단계는 퍼널 복구다.

## Primer 지원서 — 시드 프로그램 57개 조사

세션 6(9h 57min, 62 tool calls)에서 Primer 액셀러레이터 29기 지원 준비를 했다. 마감 2026-06-28, 표준 조건은 1억원 투자 + post-money 10억원 = 지분 약 10%.

200자 자기어필 문항 초안 3종을 만들고 나서 "Primer급 대안도 찾아달라"는 요청이 들어왔다. Workflow를 5개 카테고리(정부지원사업·민간 액셀러레이터·대기업/금융권 오픈이노베이션·AI특화/글로벌·상시)로 병렬 fan-out했다. 에이전트 5개, 209회 검색·검증, 57개 프로그램 조사.

1인 창업자·AI 자동화 B2B·트랙션 보유 조건으로 필터링하니 지금 당장 쓸 수 있는 카드가 7개 나왔다. 마감 순으로 정리하면 DIPS Link-up AX 2차(6/22), DHP 파트너십(상시), Primer 29기(6/28) 순이다. 1분짜리 영상 대본도 같은 세션에서 썼다.

## daymoon 포토그래퍼 사이트 — 293장, 어드민, Vercel 배포

세션 7(10h 13min, 216 tool calls)은 daymoon 사진 작가 사이트 리뉴얼이었다. 현재 상태 파악부터 시작했더니 사진이 293장 있었다.

방향 선택지 4종을 먼저 보여줬고 "화이트 큐레이션" 방향이 선택됐다. 홈 → 풀와이드 히어로 슬라이드쇼(대표작 12장 크로스페이드) → 예약 CTA 구조로 잡고 갤러리를 동적 그리드로 다시 썼다.

중간에 "메인화면 이상하니까 그냥 갤러리로 바로 가게 해줘" 요청이 들어왔다. 인트로 페이지 코드 170줄을 지우고 갤러리 직행으로 바꿨다.

관리자 페이지도 만들었다 — 비밀번호 없이 접근 가능하게(요청대로). Vercel Blob Storage API로 사진 업로드·삭제, 카테고리 관리, 시즌별 예약 관리 기능이 붙었다. 배포는 `daymoon-pic-motion.vercel.app`.

도중에 ack 파일 경합이 두 번 있었다. 다른 세션이 design-gate ack 파일을 덮어쓰는 패턴이다. 세션 ID를 OK 파일에 직접 박아 경합을 우회하는 방식으로 통과했다.

도구 분포: Bash 70회, Write 27회, TaskUpdate 26회, Edit 22회, Read 19회.

## 사주 사이트 리뉴얼 — gpt-image-2로 실제 이미지 생성

세션 9(11h 33min, 337 tool calls)가 이날 두 번째로 긴 세션이었다. 전통 사주 컨셉으로의 리포지셔닝이 먼저 나왔다.

"AI 리포트라고 하면 결제 플랫폼이 반려하지 않나?" — 반대였다. 6/11 실측 데이터에서 Etsy 자연실험을 확인했을 때, 'AI Reading' 전면 샵은 판매 0건, 인간 페르소나 샵은 464건이었다. 결제 플랫폼 심사는 랜딩 카피가 아니라 서비스 카테고리 자체(점술/운세)를 본다. 포장을 바꾸는 전략이 아니라 점술을 금지하지 않는 결제 레일을 찾는 게 맞다는 결론이었다.

리뉴얼 방향: 딥 잉크 인디고 + 골드 헤어라인 + Fraunces 세리프. three.js 코스믹 배경은 이전 사이트에서 이식했다. 별을 골드 틴트로, 드리프트 속도를 낮춰 '천천히 흐르는 밤하늘' 무드로 조정했다.

"이미지 필요한 거 gpt-image-2로 만들어달라"는 요청이 들어왔다. `genimg.py`, `genimg-ink.py` 스크립트를 만들고 BackgroundTask로 4종 이미지 생성을 걸었다. 생성 한도가 막혀 잠깐 대기 후 허용되자 바로 실행했다.

도형 SVG 차트가 "유치하다"는 피드백에 제거하고 스크롤 연동 패럴랙스·마이크로 인터랙션으로 대체했다. 7로케일 번역은 서브에이전트에 위임했다가 세션 한도로 실패해서 이어서 처리했다.

## 커피챗 어드민·결제·TTS — 14h 23min, 476 tool calls

세션 10이 이날 최장 세션이었다. 어드민 대시보드, 유저 인증, 토큰 사용량 추적, 결제, TTS를 한꺼번에 붙이는 작업이었다.

기술 스택 선택: DB는 Turso(SQLite 엣지 배포), 결제는 PayPal(글로벌 서비스·점술 제한 없는 레일). API 키가 세션 중에 붙여넣기로 들어왔다. Claude API 키(`sk-ant-api03-...`)와 OpenAI 키(`sk-proj-...`)를 각각 `.env`에 기록하고 TTS를 붙였다.

Git 이메일이 `jidong@jidongui-iMac.local`로 박혀 있어서 Vercel 배포가 "commit author email is not valid"로 막혔다. git 설정을 수정하고 다시 푸시해서 통과시켰다.

어드민 기능 목록: 유저별 이메일/비밀번호 로그인, 요청별 토큰 사용량 테이블, 결제 내역, 크레딧 조정, 유저 관리. `next-intl`로 7개 로케일도 추가했다. 포트폴리오 보강·이력서 임포트·대시보드 다시보기 UI는 각각 서브에이전트에 쪼개서 병렬 처리했다.
